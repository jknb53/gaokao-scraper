#  универсальный загрузчик тестовых работ Gaokaozhitongche (通用高考直通车试卷下载器)

这是一个Python脚本，可以从 `app.gaokaozhitongche.com` 网站上下载指定的试卷资源。

## ✨ 主要功能

- **交互式下载**: 运行后可根据提示输入试卷URL或ID，进行下载。
- **智能识别**: 无论输入的是完整URL还是仅ID，都能自动解析。
- **自动命名**: 自动抓取试卷的官方标题，用于命名文件夹和PDF文件，一目了然。
- **整合为PDF**: 将下载的所有PNG图片按顺序自动合并成一个高质量的PDF文件，方便打印和分享。
- **循环使用**: 下载完成后可继续输入新的URL，无需重复运行脚本。

## ⚙️ 环境要求

- Python 3.x
- 网络连接正常

## 🚀 安装与使用

1.  **克隆或下载项目**
    ```bash
    git clone https://github.com/你的用户名/你的仓库名.git
    cd 你的仓库名
    ```

2.  **安装依赖库**
    项目所需的库已在 `requirements.txt` 中列出。运行以下命令一键安装：
    ```bash
    pip install -r requirements.txt
    ```

3.  **运行脚本**
    ```bash
    python scraper.py
    ```

4.  **根据提示操作**
    脚本启动后，请根据提示输入您想要下载的试卷URL或ID，然后按回车键。
    ```
    请输入试卷的URL或ID (输入 'q' 或 'quit' 退出): https://app.gaokaozhitongche.com/newsexam/h/YMOAdvEg
    ```
    当您想结束程序时，输入 `q` 或 `quit` 并按回车。

## 📝 输出文件

每下载一份试卷，项目都会在当前目录下生成：
- 一个以**试卷标题命名**的文件夹，里面存放着所有原始的 `.png` 图片。
- 一个以**试卷标题命名**的 `.pdf` 文件，这是由所有图片整合而成的最终成品。
